Questions:

  • How web works?
  • what is client?
  • what is server
  • what is ISP & DNS?

Answer:

  • How web works: The web works through a client-server model, where your device's web browser acts as the client requesting information and a remote computer called a server stores and delivers the website.
  • What is clients: is a person or organization that receives professional advice, services, or ongoing support from a specialist or a business.
  • What is server: a computer or software program that provides data, resources, or services to other computers—called clients—over a network or the internet.
  • What is ISP & DNS?: An ISP stands for an Internet Service Provider. It is a company or organization that gives homes, businesses, and mobile devices access to the internet while DNS stands for the Domain Name System. It acts as the "phonebook of the Internet and it communicate using numerical IP addresses (such as 192.0.2.1 or IPv6 equivalents), while humans prefer easy-to-remember domain names.
